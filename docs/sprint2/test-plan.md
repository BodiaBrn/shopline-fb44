# План тестування продукту ShopLine (Спринт 2)

**1. Продукт і межі тестування:**
Об'єктом тестування є інтернет-магазин ShopLine. Межі тестування охоплюють: каталог товарів, кошик, процес оформлення замовлення, кабінет користувача та безпеку платежів.

**2-4. Рівні та типи тестування (єдина таблиця)**
Детальний план тестування знаходиться у Google Таблиці: 
[План тестування ShopLine (Google Sheets)](https://docs.google.com/spreadsheets/d/1eqvlNB9grbJJzgWoxkzbw6xjNo75nXl9g-yqV5zHjbg/edit?usp=sharing)

**5. Інструменти, середовище, тестові дані**
*   **Середовище:** Тестовий стенд (Staging), локальні машини розробників.
*   **Інструменти:** Google Chrome (DevTools), Burp Suite, Postman, Apache JMeter.
*   **Тестові дані:** Тестові облікові записи покупців (з коректними та недійсними даними), мок-дані для API, тестова база товарів (до 100 позицій).

**6. Ризики і припущення**
*   Недоступність тестового середовища через оновлення заблокує системне тестування.
*   Припущення: Сторонній платіжний шлюз буде доступний у режимі пісочниці (Sandbox) для тестів інтеграції.
