# Спринт 2: Аудит вимог і стратегія тестування

Дисципліна: Технології забезпечення якості програмних засобів  
Команда: ФБ-44 (Група B)  
Продукт: П1 «ШопЛайн» (ShopLine)  

## Мета спринту
Проведення незалежного командного аудиту специфікації вимог (SRS 1.0) за 6 критеріями якості, виправлення знайдених дефектів та розробка плану тестування (Test Plan) для покриття функціоналу продукту.

## Склад команди та обов'язки (Спринт 2)
* Вадим Костюк – Керівник тестування (Test Lead): декомпозиція задач, модерація зведення дефектів, сценарій Demo.
* Олександр Шандра – Тест-аналітик (Test Analyst): консолідація реєстру дефектів, створення SRS 1.1 із журналом змін.
* Ярослав Мулявка – Інженер із тестування (Test Engineer): розробка плану тестування (7 рівнів, ≥15 типів).
* Богдан Алферов – Скрам-майстер (Scrum Master): ведення таблиці задач, проведення ретроспективи, рецензування артефактів.
* Богдан Барановський – Аудитор-опонент (Auditor-Opponent): опонування спірних дефектів, підготовка питань від замовника, аудит DoD.
