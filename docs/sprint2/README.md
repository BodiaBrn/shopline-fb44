- JDK 17 (Temurin), Maven 3.9, Chrome або Firefox (драйвер встановлює Selenium Manager)
- JUnit 5 (Jupiter 5.10), Selenium 4 (selenium-java 4.21) — підтягуються з `pom.xml`
