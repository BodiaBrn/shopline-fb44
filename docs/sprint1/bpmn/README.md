## 1. Загальні відомості та інструментарій

У цьому каталозі представлено вихідні файли моделей ключових бізнес-процесів інтернет-магазину «ШопЛайн» та їх експортовані графічні копії.

* **Інструмент моделювання:** [diagrams.net](https://app.diagrams.net/) (draw.io) версії 24+.
* **Нотація:** BPMN 2.0 (Business Process Model and Notation).
* **Формати файлів:**
  * `.drawio` — вихідні XML-файли для рецензування структури та подальшого масштабування.
  * `.png` — графічний растровий експорт для включення до фінального звіту та візуального аудиту.
---
## 2. Як відкрити та переглянути файли

1. Відкрийте браузер і перейдіть за адресою [app.diagrams.net](https://app.diagrams.net/).
2. Оберіть пункт **File → Open from → Device...** (або просто перетягніть необхідний файл `.drawio` безпосередньо у вікно вебпереглядача).
3. Для збереження змін та експорту скористайтеся меню **File → Export as → PNG...** (масштаб 200%, білий фон).
---
## 3. Реєстр моделей бізнес-процесів

Відповідно до нормативу Спринту 1 для команди з 5 осіб, змодельовано всі 4 ключові процеси з легенди продукту:

| № | Файл діаграми | Графічний файл | Назва бізнес-процесу | Використані елементи BPMN 2.0 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | `01_order.drawio` | `01_order.png` | **Оформлення замовлення** | Шлюзи XOR за даними (авторизація, оплата), Event-Based XOR (очікування оплати / відповіді), паралельний шлюз AND (резервування + рахунок), згорнутий підпроцес `[+]` («Комплектація і відправлення»), таймер 24 год, об'єкт «Кошик», сховище «Каталог товарів». |
| 2 | `02_return.drawio` | `02_return.png` | **Повернення товару** | Шлюзи XOR за даними (строк 14 днів, огляд стану товару), Event-Based XOR, підпроцес `[+]` доставки, об'єкти даних «Заява на повернення» та «Накладна повернення», Message Flows між пулами. |
| 3 | `03_contact.drawio` | `03_contact.png` | **Обробка звернення з контактної форми** | Шлюз XOR за даними (класифікація: менеджер / технічний адміністратор), зворотний цикл уточнення клієнта, події отримання повідомлень, об'єкт даних «Тікет». |
| 4 | `04_restock.drawio` | `04_restock.png` | **Поповнення складу** | Умовна стартова подія («Залишок < min»), шлюз Inclusive OR (паралельні запити постачальникам), Event-Based XOR (очікування реакції постачальника), XOR за даними (рекламація), об'єкт «Список дефіциту». |
